# 記念訪問カードづくり

名前と写真を入れて、来館の記念カードを作れるツールです。トーン（色味）・天気・気温・ひとことコメントを添えて、その場でオリジナルの記念カードを生成し、画像として保存できます。

## 主な機能

- 名前・写真のアップロード（ドラッグでの位置調整、ズーム対応）
- トーン（青系／オレンジ系／シルバー系／緑系／夕焼け系）の選択
- 天気・気温・フリーコメント（すべて任意項目）の入力
- レア度演出（ノーマル／レア／キラ／にじ／でんせつ）付きの生成
- 「ラメ仕上げ」の豪華枠オプション
- 生成したカードをPNG画像として保存

## 技術構成

- [Next.js](https://nextjs.org/) 15 / [React](https://react.dev/) 19 / TypeScript
- 外部APIへの通信は行わない、完全ローカル動作（サーバー・クライアントとも追加の環境変数は不要）
- カードの描画はすべてCanvas 2D APIで実装

## ローカルでの起動方法

```bash
npm install
npm run dev
```

`http://localhost:3000` にアクセスすると起動します。

```bash
npm run build
npm run start
```

で本番ビルドの起動もできます。
